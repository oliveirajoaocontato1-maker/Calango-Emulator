# Calango Emulator v1.0

Emulador de Nintendo Switch 2 e Switch para Windows, ajustado para placas **AMD Radeon** e feito
sob medida para **The Legend of Zelda: Ocarina of Time**. Também funciona em NVIDIA e Intel.

## ⬇️ Baixar

**[Clique aqui para baixar o Calango Emulator](https://github.com/oliveirajoaocontato1-maker/Calango-Emulator/archive/refs/heads/main.zip)**
(ou use o botão verde **Code → Download ZIP** acima).

## ▶️ Como jogar

1. Extraia o `.zip` inteiro em uma pasta (não rode de dentro do `.zip`).
2. Abra **`calango.exe`**.
   Se aparecer "O Windows protegeu o computador", clique em **Mais informações → Executar assim mesmo**.
3. Clique duas vezes no calango (ou em **+ Adicionar jogos**) e escolha a pasta do seu jogo.
4. Clique duas vezes no jogo. Pronto.

Já vem tudo configurado para o melhor desempenho: FSR 3.1 com Native AA, geração de quadros
embutida, apresentação assíncrona, filtro anisotrópico 16x e FPS sem trava. Não precisa mexer
em nada.

Na primeira vez que abrir um jogo, o emulador monta os shaders da sua placa ("Building shaders").
Isso acontece uma vez só; o botão **Skip** começa o jogo na hora e o resto é montado enquanto você
joga.

## 💻 Requisitos

- Windows 10 ou 11 (64 bits)
- Placa de vídeo com Vulkan 1.3 e driver atualizado
- 16 GB de RAM (memória virtual do Windows "gerenciada pelo sistema")

Use apenas jogos que você obteve legalmente. Jogos, chaves e firmware não estão incluídos.
